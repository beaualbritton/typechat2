# typechat²

#### cross platform websocket chatrooms with bun

> [!NOTE]
> typechat can be ran locally, though i plan to deploy the web client & server online (soon)
----

### run
*install the [dependencies](#dependencies)*
```bash
# run from root dir./
docker compose up --build
# cli 
bun run cli
```

that's it!

### dependencies
* [docker](https://docs.docker.com/engine/install)
* [bun](https://bun.com/docs/installation)
